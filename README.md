# 快捷粘贴 QuickPaste

快捷粘贴 QuickPaste 是一款轻量、简洁的 Windows 剪贴板历史工具，支持文字、图片、文件、收藏和便签分类管理，适合日常办公、聊天回复、资料整理和高频复制粘贴场景。

## 最新版本

- 当前版本：0.8.13
- 更新类型：普通更新
- 安装包：QuickPasteSetup-v0.8.13.exe
- 便携版：QuickPaste-v0.8.13-portable.zip

## 主要功能

- 支持文字、图片、文件历史记录
- 支持收藏、置顶、搜索、批量选择和批量删除
- 支持便签功能，可按顺序组合文字、图片和文件
- 支持白天模式、黑暗模式和界面字号设置
- 支持主面板固定常驻、最小化、最大化和隐藏
- 支持在线下载更新
- 支持作者信息、联系方式和赞助入口
